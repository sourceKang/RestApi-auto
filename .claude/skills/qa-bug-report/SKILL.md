# QA Bug Report 共用入口

先讀取專案根目錄的
[共用 skill](../../../.codex/skills/qa-bug-report/SKILL.md)，
並依該檔完整流程執行。共用流程只在該檔維護，不在這裡複製。

共用 skill 提到的 references/ 相對於 .codex/skills/qa-bug-report/；
需要 REST／CLI 範例時，讀取
[REST／CLI 範例](../../../.codex/skills/qa-bug-report/references/rest-cli-bug-template.md)。

Redmine 內容另依
[專案 bug 範本](../../../docs/redmine_bug_template.md)。
缺少對應 MCP 或登入設定時，先完成草稿並說明外部寫入尚未執行；
不得把撰稿要求當作發送或更新外部系統的授權。
