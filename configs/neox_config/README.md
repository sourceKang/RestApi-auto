# NeoX Config Data

NeoX config test data is grouped by feature area.

- `ge/`: GE interface payloads, probes, show-command references, and negative cases.
- `nni/`: NNI interface min/max accepted payloads.
- `vlan/`: VLAN min/max payloads.
- `ont/`: ONT create min/max payloads.
- `profiles/`: NeoX profile cases, CLI verify mappings, min/max split payloads, observed notes, and invalid-case placeholders.
- `reference/`: Swagger/User Guide derived references and the NeoX feature test data index.

Keep new NeoX config files inside the matching feature folder so tests and data remain easy to trace.
